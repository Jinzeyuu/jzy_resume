01 驾驶护航“DriveGuard”​

（1）竞赛级别​

  • 第六届全球校园人工智能算法精英大赛---全国赛二等奖---第一负责人

（2）摘要​

DriveGuard是一款基于先进的多模态情感识别技术、专为驾驶安全设计的驾驶员情绪监测系统。该系统通过摄像头和麦克风捕捉驾驶员的面部表情和语音信号，结合双层LSTM和多头注意力机制网络模型与DEQ融合的视听情感识别模型，准确识别驾驶员的消极情绪状态（如疲劳、焦虑、抑郁等）。通过智能分析情绪变化，系统及时发出预警，帮助驾驶员调整情绪，避免危险驾驶行为，从而有效提升行车安全性。 DriveGuard采用了双层LSTM网络捕捉时间依赖关系，并结合Transformer中的多头注意力机制，实现不同模态间的有效特征融合。还引入DEQ融合方法动态平衡多模态特征，不断地特征提纯和迭代优化，使得系统的精度和实时性上达到了领先水平。 该系统适用于智能驾驶、公共交通、无人驾驶和职业司机的情绪监测，不仅能够有效减少因情绪波动导致的交通事故，还可作为驾驶员健康管理和心理监控的重要工具，为智慧交通和车联网提供强有力的技术支持。DriveGuard致力于成为智能驾驶领域的情绪安全守护者，推动交通系统的智能化与安全性升级。

（3）获奖证明​

02 让“火水烟”无处可藏--基于Yolov5实时检测的安全防护​

（1）竞赛级别​

  • 第十四届中国大学生服务外包创新创业大赛---西部区域赛三等奖---核心成员

（2）摘要​

本项目针对的应用场景包括但不限于校园、电力系统场所、公共场所以及企业等。安全在我们的工作、生活中无时无刻都需要它，安全工作是一项系统工程，涉及到生产、生活的方方面面。安全工作需要我们无处不在的做好防范，在日常工作中，只有真正把安全责任落到实处，才能确保企业的长治久安。 场景内的安全问题，比如火灾、漏水造成的事故会给企业和组织带来巨大的经济损耗或设备寿命影响，本次项目通过深度学习YOLOV5模型对网上开源数据库火焰、香烟、积水进行多次训练，使得模型能够由很好的检测效果，在现实检测中具有很好的准确性以及泛化性。 以校园安全为例，应当注意对校园内的火灾隐患进行检测，尽量在火灾早期进行警示，避免人员和财务损伤；对于地面的坑洼积水进行检测识别，即使进行保修，避免学生因此摔倒受伤；学校属于无烟区域，对香烟进行检测，及时处理学生的不良行为以及起到对教职工进行行为规范的作用。 针对以上的三种安全检测相关的目标识别方法，设计出一个安全检测项目“让“火水烟”无处可藏--基于Yolov5实时检测的安全防护”用于特定情境下的安全检测。本项目可以根据用户需求，进行适当调整。将集成好的检测模块打包为一个整体，调用监控摄像头进行实时检测，将检测到的信息反馈，如检测到目标物，则进行警报，使情况得到及时处理。

（3）获奖证明​
