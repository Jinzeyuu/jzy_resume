语法展示

帮助文档使用 Markdown 编写。下面按常用写法说明各自的作用、规则和效果。

标题​

# 的数量表示标题级别。# 和标题文字之间要有一个空格。

写法级别用途
# 标题一级页面标题，一篇文档只放一个，写在正文开头
## 标题二级主要章节，会出现在右侧目录
### 标题三级二级章节下的分节，会出现在右侧目录
#### 标题四级更细的小节，不进入右侧目录

二级标题示例：

这是二级标题​

这是三级标题​

这是四级标题​

# 这是一级标题

## 这是二级标题

### 这是三级标题

#### 这是四级标题

标题会自动生成页内锚点。跳转到上面的二级标题时，链接写为 [二级标题](#这是二级标题)。

段落​

我是第一行。 我是第二行（第一行结尾若 没有/只有一个 空格，则一二行属于同一段落）。

这是第二段。

我是第一行。
我是第二行（第一行后有两个空格，故一二行属于不同段落）。

我是第一行。
我是第二行（第一行结尾若 没有/只有一个 空格，则一二行属于同一段落）。

这是第二段。

我是第一行。  
我是第二行（第一行后有两个空格，故一二行属于不同段落）。

文字样式​

用样式标出按钮、字段和需要强调的词，不要整段加粗。

这是普通文字，这是加粗，这是斜体，这是删除线，这是行内代码。

效果写法适用情况
加粗**文字**按钮、菜单、页面名称
斜体*文字*需要轻微强调的词
删除线~~文字~~已废弃或被替代的内容
行内代码`文字`字段名、文件名、固定取值

加粗和行内代码可以同时使用，例如 名称，写法是 **`名称`**。

列表​

列表用于并列内容或操作步骤。列表前空一行，每一项单独占一行。

无序列表表示彼此独立、没有先后顺序的内容：

  • 第一项
  • 第二项
    • 第一项的补充
    • 第一项的另一条补充
  • 第三项

有序列表表示必须按顺序完成的步骤：

  1. 打开目标页面。
  2. 填写必填信息。
    1. 填写名称。
    2. 选择类型。
  3. 点击确定并查看结果。
- 第一项
- 第二项
  - 补充说明

1. 第一步
2. 第二步
   1. 步骤中的细分操作
3. 第三步

嵌套项比上一层多缩进两个空格。步骤有固定顺序时用有序列表，只是罗列要点时用无序列表。

图片​

图片文件放在项目的 static 目录中。正文引用时以 / 开头，不写 static。例如文件实际位置是 static/img/book.svg，引用路径写成 /img/book.svg。

![功能页面](/img/book.svg)

方括号中的文字是图片说明。图片无法显示时，页面上会显示这段文字。说明应写清图中是哪个界面，例如“新建页面”或“结果列表”。图片单独占一行，放在对应步骤附近。

链接​

链接由显示文字和地址组成。显示文字写在方括号里，地址写在圆括号里。

站内文档：说明文档1

其他文档中的章节：参数说明

本页章节：跳到提示框

外部地址：百度

[说明文档1](/docs/catalog_1/doc_1)

[参数说明](/docs/catalog_1/doc_2#参数说明)

[跳到提示框](#提示框)

[百度](https://baidu.com/)

站内文档地址以 /docs/ 开头，后面跟文件相对 docs 目录的路径，不带 .md。跳到某一节时，在地址后加上 # 和该节标题。标题中的空格在锚点里会被去掉。

引用​

引用用于示例、补充一句说明，或标出界面上的原文。行首写 >，后面空一格。

名称在同一列表中不能重复。

多行内容属于同一条引用时，每一行都以 > 开头：

第一行说明。

第二行说明。

> 名称在同一列表中不能重复。

> 第一行说明。
>
> 第二行说明。

表格​

表格适合对照说明字段、状态和取值。第一行是表头，第二行用 - 分隔，从第三行开始是内容。

配置项是否必填说明
名称是在列表中显示的名称
说明否对用途的补充描述

分隔行中的冒号控制对齐方式：

左对齐居中右对齐
文字文字文字
| 配置项 | 是否必填 | 说明 |
| --- | --- | --- |
| 名称 | 是 | 在列表中显示的名称 |

| 左对齐 | 居中 | 右对齐 |
| :--- | :---: | ---: |
| 文字 | 文字 | 文字 |

单元格中可以加粗，也可以放链接。一个单元格里不放多段文字和列表。

分割线​

分割线用于隔开同一页里相互独立的大段内容。单独一行写 ---，上下各空一行。

---

提示框​

提示框用来突出一段不能被正文淹没的内容。第一行写 :::类型，需要自定义标题时在类型后空一格写标题，最后单独一行写 :::。

类型适用情况
note补充背景，不读也不影响完成操作
tip可选的做法或更方便的操作建议
important不遵守就无法得到正确结果
caution操作前必须确认，否则可能产生错误数据
danger会造成无法恢复的后果
说明

这是补充背景。

建议

不确定时先保持默认值。

重要

带 * 的项目为必填项。

注意

修改类型后，已有数据可能无法按原方式处理。

危险

删除后不可恢复。

:::note[说明]
这是补充背景。
:::

:::tip[建议]
不确定时先保持默认值。
:::

:::important[重要]
带 * 的项目为必填项。
:::

:::caution[注意]
修改类型后，已有数据可能无法按原方式处理。
:::

:::danger[危险]
删除后不可恢复。
:::

::: 必须各自单独占一行，不能和正文写在同一行。提示框内可以包含加粗、列表和链接。一篇文档里只把真正需要停下来阅读的内容放进提示框。

代码​

行内代码用一对反引号，适合字段名和文件名，例如 名称。

多行内容使用代码块。开头的三个反引号后面写语言名称，系统会按该语言着色；只需要原样展示时写 text。代码块结束时单独一行再写三个反引号。

名称: 示例名称
类型: 文本
{
  "name": "示例名称",
  "type": "text"
}
SELECT id, name, type
FROM fields
WHERE type = 'text';
#include <iostream>
int main() {
    std::cout << "hello" << std::endl;
    return 0;
}
name = "示例名称"
type = "text"
print(f"{name}: {type}")
```此处填写代码的语言
我是代码
```

代码块中的内容按原样显示，其中的 **、# 不会变成加粗或标题。
